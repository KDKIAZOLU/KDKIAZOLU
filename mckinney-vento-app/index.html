Import Summary

How it works

  • 1
    The file is parsed fully offline (a small built-in ZIP/DEFLATE + XML reader handles .xlsx; a custom parser handles .csv).
  • 2
    Every column header is matched against a bilingual (English/Spanish) synonym dictionary to identify its meaning — e.g. "Nombre del estudiante" and "Student Name" both map to studentName.
  • 3
    Repeating "add another student" blocks are auto-detected so multiple children per family are captured correctly, regardless of how many blocks the form contains.
  • 4
    School names are corrected against the official reference list using exact match, known aliases/acronyms, and fuzzy matching — low-confidence guesses are queued for your review, never silently guessed.
  • 5
    McKinney-Vento eligibility is determined per family from the housing question plus corroborating follow-up answers.
  • 6
    Review flagged items in tabs 2–4, then explore the Dashboard and export filtered data any time.
